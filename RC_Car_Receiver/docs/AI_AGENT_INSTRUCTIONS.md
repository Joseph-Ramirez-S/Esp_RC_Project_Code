# AI Agent Mandatory Documentation Instructions

## Purpose
This document defines mandatory instructions for AI agents working in this repository.

## Mandatory Rule
- AI agents must update the documentation whenever they make any change to code, configuration, design, or behavior.

## When to update documentation
- New features or functionality added
- Existing features modified
- Bug fixes applied
- API or protocol changes
- Build or deployment process changes
- Any changes that affect other developers, users, or maintainers

## Documentation expectations
- Add or update docs in the relevant `docs/` file(s)
- Keep documentation accurate and aligned with the implemented changes
- Use clear, concise language
- Include examples when helpful
- Reference affected files, APIs, or modules where appropriate

## Enforcement
- No code or configuration update should be considered complete until corresponding documentation updates are made.
